1 · Raccogli i codici

A mano · per pochi studenti

Da Classroom apri le schede consegnate una dopo l'altra, copia la prima pagina e incollala qui sotto, anche così com'è: la pagina trova da sola le righe che iniziano con BRD-. Puoi incollare più schede di seguito.

Tutta la classe in un colpo · con uno script, una volta sola

Lo script legge tutte le schede della cartella Drive del compito e crea un documento «Codici raccolti», con il nome della scheda accanto a ogni codice. Poi incolli qui il contenuto di quel documento. In più, la pagina controlla che il nome scritto nel codice corrisponda alla scheda da cui arriva.

Istruzioni e script per raccogliere i codici di tutta la classe
  1. In Drive apri la cartella del compito: Classroom › nome del corso › titolo del compito. Dentro ci sono le schede degli studenti.
  2. Copia l'ID della cartella: è la parte dell'indirizzo che viene dopo /folders/.
  3. Vai su script.google.com › Nuovo progetto, cancella il contenuto e incolla lo script qui sotto.
  4. Nella riga ID_CARTELLA sostituisci il segnaposto con l'ID copiato, salva e premi Esegui. La prima volta Google chiede l'autorizzazione a leggere Drive e Documenti: concedila con il tuo account della scuola.
  5. Nella stessa cartella compare il documento Codici raccolti: aprilo, seleziona tutto, copia e incolla qui sotto.
/**
 * Raccoglie i codici delle palestre (BRD-COL e BRD-FON) da tutti i Documenti Google
 * di una cartella di Drive, per esempio la cartella di un compito di Classroom.
 * Crea nella stessa cartella il documento «Codici raccolti»: una riga per codice,
 * con il nome della scheda da cui arriva.
 */
const ID_CARTELLA = 'INCOLLA-QUI-ID-CARTELLA';

function raccogliCodici() {
  const cartella = DriveApp.getFolderById(ID_CARTELLA);
  const schede = cartella.getFilesByType(MimeType.GOOGLE_DOCS);
  const codice = /BRD-(?:COL|FON) \|[^\n\r]*?\| #[0-9A-Z]{5}/g;
  const righe = [];
  while (schede.hasNext()) {
    const f = schede.next();
    if (f.getName().indexOf('Codici raccolti') === 0) continue;
    const testo = DocumentApp.openById(f.getId()).getBody().getText().replace(/\u00a0/g, ' ');
    const trovati = testo.match(codice) || [];
    if (trovati.length === 0) righe.push(f.getName() + '\t(nessun codice)');
    trovati.forEach(function (c) { righe.push(f.getName() + '\t' + c); });
  }
  const quando = Utilities.formatDate(new Date(), Session.getScriptTimeZone(), 'yyyy-MM-dd HH.mm');
  const doc = DocumentApp.create('Codici raccolti ' + quando);
  doc.getBody().setText(righe.join('\n'));
  doc.saveAndClose();
  DriveApp.getFileById(doc.getId()).moveTo(cartella);
  Logger.log(righe.length + ' righe raccolte: ' + doc.getUrl());
}

3 · Risultato

    Studente per studente

    Per ogni studente e ogni palestra si usa il codice valido dell'ultimo tentativo (quello con più ripetizioni). Le righe in rosso hanno solo codici con firma non valida e non entrano nelle medie.

    La firma finale (#) dimostra che la riga non è stata ritoccata a mano, non chi l'ha prodotta: per questo, quando il codice arriva con il nome della scheda, la pagina controlla anche che i due nomi corrispondano.
