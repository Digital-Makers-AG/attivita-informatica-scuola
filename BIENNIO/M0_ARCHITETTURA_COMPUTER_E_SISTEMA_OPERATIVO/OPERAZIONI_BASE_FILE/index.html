In breve

Copia o sposta?

🎯 Obiettivo

Copiare, spostare, rinominare ed eliminare file sul PC e in Drive; comprimere una cartella in ZIP.

🔩 Materiale

I computer degli studenti; tre file di prova; la cartella di Drive dell'attività precedente.

📤 Consegna

Archivio primo_anno_cognome.zip e scheda con il codice HWS-MOV.

Scaletta · 50 minuti

Palestra

🔄

Copia o sposta?

  • 11 passi con due finestre affiancate e il contatore degli elementi (prima si prevede, poi si prova): selezionare · copiare · spostare · copia e originale · trascinare · la trappola della chiavetta · rinominare · il Cestino · lo stesso nome · Google Drive · il Cestino di Drive
  • Sfida, 8 compiti: A prevedere (3) · B copiare e spostare (3) · C Google Drive (2)
  • Circa 15 minuti · codice HWS-MOV
▶ Prova la palestra

File HTML autonomo: funziona online e offline (doppio clic), senza login. Alla fine dà una riga di codice firmata, da incollare nella scheda; un passo o una domanda saltati valgono zero e gli errori restano anche rifacendo la sfida. Alla fine lo studente può rifare solo la sfida o ricominciare tutto da zero: in entrambi i casi il codice di prima si cancella, quindi va incollato prima.

Crea il compito

Titolo
Operazioni sui file · Metti in ordine i tuoi file
Istruzioni
Oggi copi, sposti, rinomini ed elimini file veri: prima sul PC, poi in Drive.

1. Scarica i tre file allegati: sul PC finiscono nella cartella Download.
2. In Esplora file rinominali (F2) con la regola dei nomi: tutto minuscolo, _ al posto degli spazi, niente accenti né apostrofi, date scritte AAAA-MM-GG. L'estensione non si tocca.
3. Palestra «Copia o sposta?» (15 minuti): —
   Alla fine premi «Riepilogo e codice» e incolla la riga HWS-MOV nella scheda.
4. Carica i tre file nella tua cartella di Drive (Nuovo › Caricamento file). Caricare è copiare: i file restano anche sul PC.
5. In Drive SPOSTA il primo file nella cartella di una materia (⋮ › Organizza › Sposta). Del secondo crea una COPIA (⋮ › Crea una copia) e sposta la copia in un'altra cartella. Dopo ogni operazione guarda la cartella di partenza: che cosa è cambiato?
6. Sposta nel cestino il terzo file, poi recuperalo (Cestino › Ripristina).
7. Sul PC crea in Documenti la cartella primo_anno_cognome, spostaci i tre file da Download e comprimila: tasto destro › Comprimi in › File ZIP.
8. Controllo: estrai l'archivio in una cartella nuova (tasto destro › Estrai tutto) e apri un file. Si apre? L'archivio è buono.
9. Allega il file ZIP.
10. Nella scheda scrivi, con parole tue, la differenza tra copiare e spostare.
11. Premi CONSEGNA.

Che cosa consegnano

L'archivio primo_anno_cognome.zip e la scheda con il codice HWS-MOV.

Come controlli (30 secondi per consegna): incolla i codici nella verifica dei codici, poi scarica due archivi a campione ed estraili. Errori tipici: cartella invece dell'archivio, estensione rimossa rinominando, copia invece di sposta, nomi con maiuscole o spazi.
